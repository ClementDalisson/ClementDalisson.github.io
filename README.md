# clementdalisson.github.io

Page personnelle de Clément Dalisson, consultant en environnement.

- `index.html` : qui je suis, convictions, projets, parcours, contact
- `projets/` : une page par projet
- `assets/style.css` : mise en page

Site statique, sans build. Publié par GitHub Pages depuis la branche `main` du dépôt `ClementDalisson.github.io`.

Les figures des pages projets sont des fragments d'interface redessinés : aucune valeur réelle n'y figure. Les valeurs sont dans les outils eux-mêmes ([calculatrice-acv](https://clementdalisson.github.io/calculatrice-acv/)).
